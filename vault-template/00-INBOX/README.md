# 00-INBOX (Frictionless Quick Capture)

> **Purpose:** A frictionless landing zone for raw ideas, unorganized voice transcripts, meeting dumps, or rough research notes.

## 📥 Rules of the Inbox:
1. **Zero Stress:** Don't worry about folders, tags, or formatting when capturing notes here.
2. **Weekly Synthesis:** Ask `/obsidian-status` (or run `/audit-vault`) to see what's piled up
   — it flags anything older than a week and offers to help file it into `Projects/`, `Areas/`,
   or `Resources/`. This is a habit you run, not something that happens on its own; see
   `rules/content-mirror-sync.md`-adjacent docs on why true ambient autonomy isn't available on
   every AI app yet.
3. **Keep It Lean, Never Delete:** Filed notes move to `00-INBOX/Processed/`, never removed —
   the original capture stays retrievable even after it's been acted on.
